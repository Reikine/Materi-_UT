# Materi UT (Universitas Terbuka)

Repository ini berisi kumpulan catatan kuliah, rangkuman modul, dan materi pembelajaran untuk perkuliahan di Universitas Terbuka (UT), khususnya mencakup materi Semester 3 dan Semester 4.

---

## 📂 Struktur Repositori

Materi di dalam repositori ini diatur berdasarkan semester dan kode mata kuliah:

*   **`SMT_003_UT/`** — Berisi rangkuman materi kuliah untuk Semester 3.
*   **`SMT_004_UT/SMT_004_SIA/`** — Berisi materi Sistem Informasi Akuntansi (SIA) untuk Semester 4.
*   **Mata Kuliah Lain (.md):**
    *   `SMT_003_Algoritma_Pemrograman.md` — Materi Algoritma dan Pemrograman.
    *   `SMT_003_Jaringan_Komputer.md` — Materi Jaringan Komputer.
    *   `SMT_003_Komputer_001.md` — Materi Pengantar Komputer / Dasar Komputer.
    *   `SMT_003_Logika_Informatika.md` — Catatan seputar Logika Informatika.
    *   `SMT_003_Pemrograman_Berorientasi_Objek.md` — Rangkuman Pemrograman OOP.
    *   `SMT_003_Rekayasa_Perangkat_Lunak.md` — Kumpulan soal dan materi RPL.
